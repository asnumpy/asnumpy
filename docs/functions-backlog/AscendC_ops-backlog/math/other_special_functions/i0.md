## 相关内容
- **dtype**：aclTensor，数据类型为所有浮点数类型。  
- **shape**：各维大小常为 16 ~ 4096，极限通常不超过 10^4；总元素常为 10^4 ~ 10^6，极限通常不超过 10^7。  
- **维度**：常为 1 ~ 2，极限通常不超过 4。  
- **功能**：计算**修正贝塞尔函数**（第一类，0 阶，I₀）。

## np 示例
```python
import numpy as np

np.i0(0.)
# 1.0

np.i0([0, 1, 2, 3])
# array([1.        , 1.26606588, 2.2795853 , 4.88079259])
```
