## 相关内容
- **dtype**：aclTensor，**输出数据类型**为 `int32`、`int64` 和浮点数类型；建议兼容复数类型。  
- **shape**：各维长度常为 1 ~ 10^3，极限通常不超过 65536；总元素常为 10^2 ~ 10^6，极限通常不超过 10^8。  
- **维度**：常为 1 ~ 2，极限通常不超过 4。  
- **功能**：计算两个数组的**点积**。一维向量返回内积；二维返回矩阵乘法；更高维按 NumPy 语义在最后一维（`a`）与倒数第二维（`b`）进行乘加并对其余维度做广播。

## np 示例
```python
import numpy as np

np.dot([2j, 3j], [2j, 3j])
# (-13+0j)

a = [[1, 0], [0, 1]]
b = [[4, 1], [2, 2]]
np.dot(a, b)
# array([[4, 1],
#        [2, 2]])

a = np.arange(3*4*5*6).reshape((3, 4, 5, 6))
b = np.arange(3*4*5*6)[::-1].reshape((5, 4, 6, 3))
np.dot(a, b)[2, 3, 2, 1, 2, 2]
# 499128
```
