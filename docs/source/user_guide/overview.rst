概览
====

AsNumpy 是一个旨在昇腾 NPU 上提供与 NumPy 高度兼容的科学计算接口的库。

主要特性
--------

* **NumPy 兼容性**: 尽可能保持与 NumPy 一致的 API，降低迁移成本。
* **NPU 加速**: 利用昇腾 NPU 的强大算力加速科学计算。
* **丰富的功能**: 涵盖数学运算、逻辑函数、随机抽样等常用模块。

API 完成情况
------------

AsNumpy 目前已实现多个核心功能模块的 API，包括：

* **数学运算模块 (Math)**: 算术运算、指数与对数、三角函数等。
* **随机抽样模块 (Random)**: 各类概率分布的随机数生成。
* **逻辑函数模块 (Logic)**: 数组比较、逻辑运算等。

更多详细信息请参考 API 参考文档。
